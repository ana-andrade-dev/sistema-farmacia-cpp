# 💊 Sistema de Caixa para Farmácia

Programa em C++ que simula o caixa de uma farmácia, desenvolvido na disciplina de AEDS I.

## Funcionalidades
- Registro de medicamentos e preços em um recibo
- Medicamentos controlados só são vendidos mediante receita
- Desconto de 15% para idosos e clientes com convênio
- Várias vendas em sequência, com faturamento total do dia

## Como compilar e rodar
```bash
g++ farmacia.cpp -o farmacia
./farmacia
```
